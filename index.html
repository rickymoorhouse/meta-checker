Machine-readability audit

Meta Checker

Enter a site or post URL to check its feeds, crawling setup, microformats, schema.org data, OpenGraph tags, IndieWeb and fediverse support, standard.site records, SocialSpec files and agent-friendly formats, and whether they all agree. Whole-site mode checks the home page and a post together.

Fetching options

Each URL is fetched directly first. Most sites block cross-origin reads of their HTML, so if a direct fetch fails the checker can retry through a CORS proxy. SocialSpec files must allow CORS, so a file that only loads through the proxy loses points.

Use the base URL of a Meta Checker proxy (see proxy/ in the repo). It reports the target's real headers, so CORS and Content-Type are checked accurately. A generic CORS proxy also works: give a URL template containing {url}. Leave the field empty to fetch directly only.
